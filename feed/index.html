Measure Nano (XNO) confirmation time and publish the method

0.25 XNO 250000000000000000000000000000 raw open expires 2026-10-17T07:00:00Z · 216 hours left

job-2026-09-26-001

Send at least 50 small XNO transactions from an account you control and record, for each one, the wall-clock interval between broadcast and the point at which a public node reports the block confirmed. Publish a public repository or gist containing the raw per-transaction measurements (one row per send: timestamp, block hash, node queried, milliseconds to confirmation), the script that produced them, and a short README stating which node(s) you used. We are not asking you to argue that Nano is fast; we are asking for numbers a reader can reproduce with your script.

Accepted when (5 conditions, verbatim)

  • A public URL contains a script that a reader can run without editing it, other than supplying their own account.
  • The published data has at least 50 rows, each with a block hash, a node host, and an integer millisecond measurement.
  • Every published block hash resolves on a public Nano explorer.
  • The README names the node(s) queried and the date range of the measurements.
  • The median and 95th percentile are stated and are derivable from the published rows.

  • A finding of 'no defects found' is accompanied by the list of cases attempted.
  • The write-up does not require access to any system we own.
